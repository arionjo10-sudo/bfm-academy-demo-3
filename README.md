# BFM Academy DEMO (practice copy)

This is a separate practice build of BFM Academy. It is NOT the real Academy.
- 50 made-up students are pre-loaded (everyone with a position has finished all four BFM classes; their leadership-track progress differs) (one is a pastor who has finished every course, including Track A and Teacher Certification).
- Open index.html in a browser. Nothing is sent anywhere. Everything is stored only in this browser.
- Director code for the demo only: DEMO1-TRYIT (real director codes are not in this package).
- Use the bar at the top: "View as" opens the Academy as any of the 50 students; "Reset demo data" puts everything back.
- Delete this folder when you are finished testing.
See WALKTHROUGH-DEMO.md for a guided test.
- v50 features to try: class gating (Track 1-3 locked until the four classes are done), class-skip requests, inline and floating announcements with arrows, scheduling, archive, and the new-events pop-up.
